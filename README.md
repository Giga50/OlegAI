# OlegAI

**Your AI. Your Future.**

OlegAI — экспериментальный проект Giga50, посвящённый созданию собственной AI-платформы с простым интерфейсом и полезными инструментами.

> Проект находится в разработке. Сейчас репозиторий содержит стартовую страницу; полноценный AI-ассистент и его функции ещё не реализованы.

## О проекте

Цель OlegAI — постепенно создать удобного ИИ-помощника для:
- общения на естественном языке;
- помощи с программированием;
- поиска идей и обучения;
- повседневных задач.

Это планы развития, а не уже доступные функции.

## Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Giga50/OlegAI.git
   ```
2. Откройте папку проекта.
3. Запустите `index.html` в браузере.

## Структура

- `index.html` — главная страница.
- `README.md` — описание проекта.
- `ROADMAP.md` — планы развития.
- `CHANGELOG.md` — история изменений.
- `CONTRIBUTING.md` — правила предложений и участия.
