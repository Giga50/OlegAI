# Как помочь OlegAI

Спасибо за интерес к проекту!

## Предложения и ошибки

1. Проверьте, нет ли уже похожего обсуждения в Issues.
2. Создайте Issue с понятным заголовком.
3. Опишите идею или проблему и шаги для её повторения.

## Изменения в коде

1. Сделайте Fork репозитория.
2. Создайте отдельную ветку для изменений.
3. Вносите небольшие и понятные коммиты.
4. Проверьте страницу в браузере, включая мобильный экран.
5. Откройте Pull Request с описанием изменений.

## Стиль

- Сохраняйте HTML, CSS и JavaScript простыми и читаемыми.
- Не добавляйте API-ключи, пароли и другие секреты в репозиторий.
- Не заявляйте о функциях, которые ещё не реализованы.

## Общение

Будьте уважительны к другим участникам и конструктивно обсуждайте предложения.
